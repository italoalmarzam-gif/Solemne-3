PROPOSITO
Dashboard interactivo para explorar y analizar jugadores de FIFA 22.

CSV local.

ARCHIVO DE DATOS
players_22.csv

FUENTE DE REFERENCIA
FIFA 22 Complete Player Dataset - Kaggle:
https://www.kaggle.com/datasets/stefanoleone992/fifa-22-complete-player-dataset

ARCHIVOS DEL PROYECTO
- app.py: aplicación principal.
- players_22.csv: conjunto de datos.
- requirements.txt: bibliotecas necesarias.

COMO EJECUTAR
1. Instalar Python.
2. Abrir una terminal en la carpeta del proyecto.
3. Instalar dependencias:
   pip install -r requirements.txt
4. Ejecutar:
   streamlit run app.py

PUBLICACION
Agregar aquí el enlace de Streamlit Community Cloud cuando la aplicación esté publicada.

DESCRIPCION
La aplicación permite filtrar jugadores por nacionalidad, liga, posición,
edad, valoración general y pie preferido. Presenta indicadores, una tabla,
gráficos de barras, histograma y dispersión, además de una comparación
entre dos jugadores e información sobre la calidad del dataset.

LIMITACIONES
Los datos corresponden a FIFA 22 y no representan las valoraciones actuales
de los futbolistas en juegos posteriores ni precios actuales del mercado.
